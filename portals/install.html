Install Diet Tracker

Your free protein tracker — a couple of taps to set up.

📱 Android only — Diet Tracker runs on Android phones. It will not install on an iPhone / iOS.
Download the app (Android)
  1. Download

    On your Android phone, tap the Download button above and let the file finish downloading.

  2. Open & install

    Open the downloaded DietTracker.apk file and tap Install.

  3. Open More details

    Because the app isn’t from the Google Play Store, Android may show a Play Protect warning. This is completely normal. Tap “More details”.

  4. Allow the installation

    Tap “Install anyway”, then OK. If asked, allow installs from this source.

  5. Sign in

    Open the app and sign in with the same email address your gym used to enroll you. That’s it — start tracking!
